# 🛠️ XAMPP MySQL 'Shutdown Unexpectedly' সমস্যার সমাধান

XAMPP-এ MySQL স্টার্ট করার সময় হঠাৎ বন্ধ হয়ে যাওয়া (Shutdown unexpectedly) একটি অত্যন্ত পরিচিত সমস্যা। সাধারণত ডেটা ফাইল করাপ্ট হলে বা পোর্টের সমস্যার কারণে এটি হয়। এই রিপোজিটরিতে এই সমস্যার সবচেয়ে কার্যকর এবং নিরাপদ সমাধানটি ধাপে ধাপে দেওয়া হলো।

---

## 🚩 এরর মেসেজটি দেখতে কেমন হয়?

যখন এই সমস্যাটি হয়, তখন XAMPP কন্ট্রোল প্যানেলে নিচের মতো লাল রঙের এরর মেসেজ দেখা যায়:

```text
[mysql]  Status change detected: stopped
[mysql]  Error: MySQL shutdown unexpectedly.
[mysql]  This may be due to a blocked port, missing dependencies, 
[mysql]  improper privileges, a crash, or a shutdown by another method.
[mysql]  Press the Logs button to view error logs and check
[mysql]  the Windows Event Viewer for more clues
[mysql]  If you need more help, copy and post this
[mysql]  entire log window on the forums

## 🔍 কেন এই এরর আসে?

  - Improper Shutdown: MySQL স্টপ না করে পিসি বন্ধ করে দিলে বা হুট করে বিদ্যুৎ
    চলে গেলে।
  - Data Corruption: ibdata1 ফাইলটি কোনো কারণে ক্ষতিগ্রস্ত হলে।
  - Port Conflict: ৩৩০৬ পোর্টটি অন্য কোনো সফটওয়্যার (যেমন: আলাদা ভাবে ইনস্টল করা
    MySQL বা Skype) ব্যবহার করলে।
  - Permission Issue: পর্যাপ্ত অ্যাডমিনিস্ট্রেটর পারমিশন না থাকলে।

## 🚀 ধাপে ধাপে সমাধান (Data Folder Fix)

আপনার আগের তৈরি করা ডেটাবেস অক্ষুণ্ণ রেখে এই সমস্যা সমাধানের সবচেয়ে সেরা পদ্ধতি
হলো এটি। নিচের ধাপগুলো অনুসরণ করুন:

## ধাপ ১: সার্ভার বন্ধ করুন

প্রথমে আপনার XAMPP Control Panel থেকে Apache এবং MySQL দুটিই বন্ধ (Stop) করে
দিন।

## ধাপ ২: ফোল্ডার রিনেম করুন

আপনার পিসিতে যেখানে XAMPP ইন্সটল করা আছে (সাধারণত: C:\xampp\mysql\), সেই
ফোল্ডারে যান। সেখানে data নামের ফোল্ডারটির নাম পরিবর্তন করে data_old করে দিন।

## ধাপ ৩: নতুন ডাটা ফোল্ডার তৈরি

একই লোকেশনে ( C:\xampp\mysql\ ) backup নামে একটি ফোল্ডার আছে। এই ফোল্ডারটি কপি
করুন এবং সেখানেই পেস্ট করুন। এবার কপি করা ফোল্ডারটির নাম পরিবর্তন করে data দিন।

## ধাপ ৪: আপনার ডেটাবেস ফোল্ডারগুলো কপি করুন

এখন data_old ফোল্ডারে ঢুকুন। সেখান থেকে আপনার তৈরি করা ডেটাবেস ফোল্ডারগুলো কপি
করে নতুন তৈরি করা data ফোল্ডারে নিয়ে যান।

⚠️ সাবধান: কপি করার সময় mysql, performance_schema, এবং phpmyadmin নামের
ফোল্ডারগুলো কোনোভাবেই কপি করবেন না। শুধুমাত্র আপনার নিজের তৈরি করা প্রোজেক্টের
ডেটাবেস ফোল্ডারগুলো কপি করুন।

## ধাপ ৫: ibdata1 ফাইল কপি করুন

সবশেষে data_old ফোল্ডার থেকে ibdata1 নামক ফাইলটি কপি করুন এবং নতুন data ফোল্ডারে
পেস্ট করে দিন (আগের ফাইলটি Replace করার অনুমতি চাইলে 'Yes' দিন)। এটি আপনার আগের
ডেটাবেসগুলোর রিলেশনশিপ ঠিক রাখবে।

## ধাপ ৬: পুনরায় চালু করুন

এখন XAMPP Control Panel ওপেন করে MySQL স্টার্ট দিন। আশা করি সব ঠিকভাবে কাজ করবে।
🎉

💡 ভবিষ্যতে এই সমস্যা এড়াতে কিছু টিপস:

1.  পিসি বন্ধ করার আগে সব সময় XAMPP থেকে Apache এবং MySQL Stop করে নিবেন।
2.  গুরুত্বপূর্ণ ডেটাবেসের নিয়মিত ব্যাকআপ (Export) করে রাখুন।
3.  XAMPP কন্ট্রোল প্যানেলটি সব সময় "Run as Administrator" হিসেবে ওপেন করুন।
